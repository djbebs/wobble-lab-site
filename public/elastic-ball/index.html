How to use it

A gel that never seems to settle.

Grab the ball, pull it aside and let go. This demonstration keeps almost all of its energy from one bounce to the next, so the wobble rings on far longer than a real gel could.

What it is modelling

The ball uses the same pressure, shape and shear constraints as the Jelly specimen. The difference is damping: it is set almost to zero, with a high restitution at the floor. That makes this an intentionally unreal material study. No real gel behaves this way.

What to notice

Firmness changes how quickly the ball deforms and returns to shape. Energy retention changes how long the bounce continues. In this preset, the response is bright, fast and almost lossless.
